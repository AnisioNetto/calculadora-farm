# Calculadora de Farm — Morro dos Caveiras

Página estática em HTML, CSS e JavaScript. Não requer servidor, banco de dados ou instalação.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub (por exemplo `calculadora-farm`).
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação e abra o endereço exibido na seção Pages. O endereço normalmente será `https://SEU-USUARIO.github.io/calculadora-farm/`.

No GitHub Free, o repositório precisa ser público para usar GitHub Pages. O site publicado é público e qualquer pessoa com o endereço pode usar a calculadora.

## Observação

A calculadora processa tudo no navegador. Ela não salva lançamentos em um banco central nem sincroniza os cálculos de uma pessoa com outra. Cada visitante calcula localmente.
